# Apex Terminal

A round-based tactical FPS built with three.js: plant or defuse the bomb, buy weapons between rounds, and fight bots that patrol, hold angles and react. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run

    node serve.ts
    # open http://localhost:8080 in desktop Chrome

WASD to move, mouse to aim, B for the buy menu, G for a grenade. Original map "Apex Terminal": two lanes, connectors, bomb sites A and B.
